# Ovim 1.9.0

Ovim 1.9.0 stops a warning about a whole class or method from repainting the
class, takes Vim's pattern syntax in search and `:s`, and closes many gaps
against Vim in operators, motions and text objects.

## Highlights

- A diagnostic no longer hides the code it is about. The underline takes the
  severity colour and the text keeps its syntax colours. A diagnostic that a
  language server reports over several lines, such as a warning about a whole
  class or method, underlines its first line only. Before, every line of the
  class was underlined and turned yellow. `<Space>e`, `]d` and code actions
  still work from every line the diagnostic covers.
- The coloured underline is used when the terminal is known to support it
  (`COLORTERM` says 24-bit colour, or `TERM` names kitty, Ghostty, Alacritty,
  WezTerm, foot or Contour). Elsewhere the underlined text takes the severity
  colour, as before. `OVIM_UNDERLINE_COLOR=1` or `=0` overrides the guess.
- The diagnostics card in the top-right corner is now a notice. It appears for
  8 seconds when diagnostics first show up in a file or when the number of
  errors rises, and then goes away. It used to stay over the code until
  dismissed and came back on every change of the count. The status line shows
  the counts all the time.
- `/`, `?`, `:s`, `:g` and pattern ranges take Vim patterns:
  `:s/\(a\)\(b\)/\2\1/`, `/\<word\>`, `:s/\s\+/_/g` and `\v` work.
  **Behaviour change:** Rust regex syntax such as `(a|b)+` must now be written
  `\(a\|b\)\+` or `\v(a|b)+`.
- `.` repeats any operator over any motion (`dge.`, `d3|.`, `d).`,
  `cge…<Esc>.`).

## Vim compatibility

Each of these was found by running the same keys in `nvim --clean` and Ovim.

- Counts reach into the next lines for `d2$`, `c2$`, `2D`, `2C` and `g~2$`.
- `d%`, `y%` and `c%` search forward for a bracket as `%` does.
- `c}` and `c{` keep the indent and the blank line.
- `gp` and `gP`. `p` and `P` of multi-line characterwise text leave the cursor
  at its start.
- Visual mode runs `^`, `_`, `|`, `+`, `-`, `W`, `B`, `E`, `H`, `M`, `L`, `(`
  and `)`. `M` goes to the middle of the lines shown.
- `<C-a>` and `<C-x>` find the number after the cursor when a `-` or `+`
  precedes it, and handle the `x` of `0x1f`.
- `:[line]pu[t][!] [x]`, `:[range]>` and `:[range]<`.
- `<C-r>{register}`, `<C-r><C-w>` and `<C-r><C-a>` on the command line and in
  a search.
- `a"`, `a'` and `` a` `` take the blanks after the quotes, or before them
  when none follow.
- `(` and `)` follow Vim's definition of a sentence: an empty line ends one,
  and the indent of a continuation line does not start one. `is` takes the
  sentence with its punctuation, `as` also the blanks around it, and both
  cross line breaks.
- In Visual mode a count or a repeated object extends the selection: `v2aw`,
  `vipip`, `vawaw`, `visis`.

## Fixes and reliability

- Where diagnostics overlap, the most severe one owns the underline. It used
  to be whichever the server listed first.
- Desktop app: the gutter and the overview ruler mark the line a diagnostic
  starts on, with the most severe one. They used to mark every line a
  diagnostic covered.
- Stop losing the first keystrokes in a terminal that answers no queries, such
  as a detached tmux session.
- For fewer false warnings in Java and Kotlin, update hyperion-lsp to 0.1.3:
  `:LspUpdate java`, or `brew upgrade hyperion-lsp` if Homebrew installed it.

## Installation

```sh
brew update
brew install ovim-editor/tap/ovim
# Already installed:
brew upgrade ovim
```

Homebrew installs the terminal editor. Release archives include both `ovim` and
`ovim-gui` for macOS and Linux on Intel/AMD and ARM64. Native desktop packages are
available as macOS DMGs and Linux DEBs and AppImages. The terminal binary does
not require GTK or WebKit; the Linux GUI requires its desktop runtime libraries.
The macOS desktop packages are unsigned.
