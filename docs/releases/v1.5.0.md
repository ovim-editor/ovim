# Ovim 1.5.0

Ovim 1.5.0 improves diff reviews and AI collaboration, with more reliable code
navigation and language-server setup.

## Highlights

- Add and edit diff review comments, then attach them to AI chat.
- Read frozen source context in diff walkthroughs.
- Diff reviews open in split view by default and use the full pane width.
- Fuzzy finder previews size their viewport correctly and highlight the target.

## Fixes and reliability

- Fix link activation in terminal AI chat.
- Encode LSP file URIs correctly for dynamic route paths.
- Pin TypeScript 6 for typescript-language-server and retry the repaired binary.
- Refuse npm package versions published less than three days ago.
- Update the Markdown sanitizer and development dependencies with security fixes.

## Installation

```sh
brew update
brew install ovim-editor/tap/ovim
# Already installed:
brew upgrade ovim
```

Homebrew installs the terminal editor. Release archives include both `ovim` and
`ovim-gui` for macOS and Linux on Intel/AMD and ARM64. Native desktop packages are
available as macOS DMGs and Linux DEBs and AppImages. The terminal binary does
not require GTK or WebKit; the Linux GUI requires its desktop runtime libraries.
The macOS desktop packages are unsigned.
