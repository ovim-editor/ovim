# Ovim 1.6.0

Ovim 1.6.0 adds mouse selection and a first-run AI chooser to the desktop app,
with fixes from a full macOS test pass.

## Highlights

- Select text with the mouse in the desktop editor: drag, double-click a word,
  triple-click a line, or shift-click to extend.
- Choose how AI chat runs the first time you open it: Claude Code on your Claude
  plan, Codex on your ChatGPT plan, or another provider. Ovim remembers the
  choice.
- Approve or deny a subagent's request from the desktop chat, allow a tool and
  remember it, and queue a message while a reply runs.
- Expand a whole unchanged gap in the diff review. Word changes are paired by
  similarity, and file headings stay in view while you scroll.
- Close source and browser tabs with their close button or a middle-click. A
  modified file stays open until it is saved.

## Fixes and reliability

- Send desktop keystrokes to the editor in the order they were typed, also when
  typing fast.
- Show the current buffer in every split pane after a buffer switch.
- Restore git change markers after a file reloads from disk.
- Stop macOS from turning two spaces into a period, or changing quotes and
  dashes, while typing in the desktop app.
- Let Cmd-A select the whole buffer in Insert mode.
- Bring the AI chat back to the side panel after a walkthrough.
- Comment on the diff line that was clicked, also in another change.
- End a mouse drag that leaves the editor where the pointer was released.
- Scroll the view with the mouse wheel without accepting completions or editing
  prompts in Insert mode.
- Keep popups and the input method at the cursor, and keep CJK text and emoji on
  the character grid.
- Map Ctrl and Cmd shortcuts on non-Latin keyboard layouts.
- Follow light themes in the desktop terminal.

## Installation

```sh
brew update
brew install ovim-editor/tap/ovim
# Already installed:
brew upgrade ovim
```

Homebrew installs the terminal editor. Release archives include both `ovim` and
`ovim-gui` for macOS and Linux on Intel/AMD and ARM64. Native desktop packages are
available as macOS DMGs and Linux DEBs and AppImages. The terminal binary does
not require GTK or WebKit; the Linux GUI requires its desktop runtime libraries.
The macOS desktop packages are unsigned.
