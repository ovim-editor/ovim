# Ovim 1.7.0

Ovim 1.7.0 installs the Java, Kotlin, Scala and Groovy language server for you,
lets you click Run and Debug next to a `main` method, and fixes undo when an
edit lands while you type.

## Highlights

- Open a Java, Kotlin, Scala or Groovy file and Ovim offers to install
  [hyperion-lsp](https://github.com/hyperion-lsp/hyperion-lsp) from its GitHub
  releases, on macOS and Linux. The debugger uses the same binary. A
  `hyperion-lsp` on `PATH` still comes first.
- Click `▶ Run` or `▶ Debug` at the end of a `main` method's line to run or
  debug it. This works in the terminal, and the desktop app now shows these
  labels too. They highlight on hover. From the keyboard, `Space c l` runs and
  `Space c L` debugs.

## Fixes and reliability

- Keep undo working when an edit lands while you type in Insert mode: an AI
  chat edit, a format or rename result, an edit the language server sends, or
  an edit through the REST API. Before, the next undo could garble the text.
  Now the text typed before the edit, the edit, and the text typed after it are
  three undo steps, as with `<C-g>u` in Vim.
- Undo with Cmd-Z in Insert mode in the desktop app. It removes the text typed
  so far and stays in Insert mode, like `<C-o>u` in Vim.
- Keep undo working in both tabs when you click another tab in Insert mode and
  keep typing.
- Keep the cursor at the end of the line when a language server edit lands in
  Insert mode.

## Installation

```sh
brew update
brew install ovim-editor/tap/ovim
# Already installed:
brew upgrade ovim
```

Homebrew installs the terminal editor. Release archives include both `ovim` and
`ovim-gui` for macOS and Linux on Intel/AMD and ARM64. Native desktop packages are
available as macOS DMGs and Linux DEBs and AppImages. The terminal binary does
not require GTK or WebKit; the Linux GUI requires its desktop runtime libraries.
The macOS desktop packages are unsigned.
