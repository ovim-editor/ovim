# Ovim 1.10.0

Ovim 1.10.0 shows the code around each result in the desktop app's live grep
and file finder, and gives the desktop app a new icon.

## Highlights

- Desktop app: live grep, the file finder and the location lists (references,
  definitions) show the selected file beside the results, as the terminal
  editor does. The pane colours the code like the editor and keeps the matched
  line in its middle, marked with the line number in the accent colour. While
  the next file loads, the last one stays on screen, dimmed.
- Desktop app: a new icon. It keeps the macOS margins and drop shadow, so Ovim
  sits at the same size as other apps in the Dock. The old icon filled the
  whole tile and looked too large there.

## Installation

```sh
brew update
brew install ovim-editor/tap/ovim
# Already installed:
brew upgrade ovim
```

Homebrew installs the terminal editor. Release archives include both `ovim` and
`ovim-gui` for macOS and Linux on Intel/AMD and ARM64. Native desktop packages are
available as macOS DMGs and Linux DEBs and AppImages. The terminal binary does
not require GTK or WebKit; the Linux GUI requires its desktop runtime libraries.
The macOS desktop packages are unsigned.
