# Ovim 1.8.0

Ovim 1.8.0 keeps the language servers it installs up to date, shows inlay
hints again without setup, and no longer overwrites a file that appeared
behind an unsaved buffer.

## Highlights

- Language servers that Ovim downloads from GitHub releases (rust-analyzer,
  hyperion-lsp and the others installed that way) no longer stay at the version
  that was current on the day of the first install. Once a day, when such a
  server starts, Ovim looks for a newer release. With `autoinstall=auto` it
  installs it for the next start; with the default `autoinstall=prompt` it
  tells you once; with `autoinstall=off` it never asks. Only releases at least
  3 days old are picked up this way.
- `:LspUpdate` updates the current file's server right away, and
  `:LspUpdate java` a named one. `:LspManager` shows the installed release and
  whether a newer one exists. A server on your `PATH` is left alone.
- Inlay hints are on by default again: parameter names in Java and Kotlin,
  types in Rust. Turn them off with `:set noinlay_hints` or
  `vim.opt.inlay_hints = false` in `init.lua`. For the Java and Kotlin fixes
  behind this, update hyperion-lsp to 0.1.1: `:LspUpdate java`, or
  `brew upgrade hyperion-lsp` if Homebrew installed it.

## Fixes and reliability

- Refuse `:w` with `E13: File exists (add ! to override)` when the file
  appeared on disk after you started a new buffer with that name, or when the
  write targets another existing file. `:w!` still overwrites.
- Keep unsaved changes and undo history when `:checktime` finds the file
  changed on disk.
- Apply the same protection when the AI chat saves a file and when a
  workspace-wide edit is written to disk.
- Request inlay hints for a file that does not end in a newline. The range
  ended one line past the last line, and a server that checks positions gave
  no hints at all.
- Show code lenses (`▶ Run`, `▶ Debug`) as soon as the server is ready, and ask
  again when a request fails.
- Notice changes in a folder that was moved into the project.
- Type `é`, `中` or an emoji in the desktop app. The key handler panicked on
  characters longer than one byte.
- Desktop app terminal: `:term`, `:terminal` and `:shell` open the terminal
  panel, `:term <command>` runs a command in a fresh session, and leaving the
  shell closes the panel. A running shell and its scrollback survive switching
  to chat or another tab.
- On macOS, report a write to a recently created file to the language server
  as a change, not as a new file.
- Give up on a GitHub request that stops answering during a server install.
  It used to wait without limit.

## Installation

```sh
brew update
brew install ovim-editor/tap/ovim
# Already installed:
brew upgrade ovim
```

Homebrew installs the terminal editor. Release archives include both `ovim` and
`ovim-gui` for macOS and Linux on Intel/AMD and ARM64. Native desktop packages are
available as macOS DMGs and Linux DEBs and AppImages. The terminal binary does
not require GTK or WebKit; the Linux GUI requires its desktop runtime libraries.
The macOS desktop packages are unsigned.
