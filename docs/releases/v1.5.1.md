# Ovim 1.5.1

Ovim 1.5.1 is a reliability and security release focused on AI safety,
language-server installs, and editing correctness.

## Fixes and reliability

- Close AI approval bypasses, including symlinked paths, and bound shell output
  streaming.
- Prevent encoding loss on save and stale search replacements.
- Keep independent cursors for tabs showing the same file.
- Preserve GUI chat drafts and browser tab ownership across async replies.
- Rediscover installed language servers from their install contracts, and stop
  re-asking to install Tailwind after it is installed.
- Publish language server executables atomically, so reinstalling a running
  server succeeds.
- Update vulnerable frontend, Claude runtime, and installer dependencies.

## Installation

```sh
brew update
brew install ovim-editor/tap/ovim
# Already installed:
brew upgrade ovim
```

Homebrew installs the terminal editor. Release archives include both `ovim` and
`ovim-gui` for macOS and Linux on Intel/AMD and ARM64. Native desktop packages are
available as macOS DMGs and Linux DEBs and AppImages. The terminal binary does
not require GTK or WebKit; the Linux GUI requires its desktop runtime libraries.
The macOS desktop packages are unsigned.
