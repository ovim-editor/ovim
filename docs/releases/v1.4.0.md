# Ovim 1.4.0

Ovim 1.4.0 expands Git review, adds integrated run/debug/test tools, and improves
Vim compatibility, language-server reliability, and performance in both frontends.

## Highlights

- **Git tools:** stage and unstage hunks or files, commit and amend through a
  message buffer, browse status and history, and navigate and resolve conflicts.
- **Diff review:** continuous split and unified views, cross-file custom reviews,
  labelled sections, guided walkthroughs, captured context expansion, search,
  shared review progress, and full-review PNG export. Saved refinements verify
  their source and support recovery when files change.
- **Run, debug, and test:** a shared launch pipeline, interactive run console,
  Java/Kotlin test integration, debugger variables and watches, breakpoint
  controls, and persistent test results available to editor AI tools.
- **Code navigation and editing:** richer completion and snippets, signature
  help, folding, breadcrumbs and outline, workspace symbols and problems,
  project search/replace, and recent files.
- **AI and desktop:** Claude Agent integration, provider permission controls,
  persistent provider/model choices, and an integrated GUI terminal. The Claude
  Agent SDK installs from npm on first use and requires Node.js and npm.

## Reliability

Vim behavior is more consistent across motions, counts, text objects, Visual
mode, registers, macros, marks, repeat, undo, and Ex commands. Git operations
handle exact filenames and deleted files correctly, and commands launched from
a diff review run in the repository being reviewed.

Language servers recover from crashes, synchronize documents more reliably, and
avoid blocking the editor on slow requests. This release also improves long-line
and split-pane rendering, Unicode selection, clipboard handling, and GUI layout.

## Installation

```sh
brew update
brew install ovim-editor/tap/ovim
# Already installed:
brew upgrade ovim
```

Homebrew installs the terminal editor. Release archives include both `ovim` and
`ovim-gui` for macOS and Linux on Intel/AMD and ARM64. Native desktop packages are
available as macOS DMGs and Linux DEBs and AppImages. The terminal binary does
not require GTK or WebKit; the Linux GUI requires its desktop runtime libraries.

The macOS desktop packages are unsigned. Model access depends on your configured
provider account. Remote editing and separate project windows remain outside
this release.
